# inbox：给夜间整理的待办条目

日常 Agent 和你在这里**追加**想长期记住的东西，夜间整理任务（`ops/dreaming.md`）读完并进 `20_wiki/`。不要直接改 wiki。

- 文件名：`YYYY-MM-DD.md`，例如 `2026-01-15.md`。同一天追加到同一个文件，不改别人写的条目。
- 处理过的条目由夜间任务登记在 `ops/state/inbox-done.md`，文件本身不删。

每条格式：

```markdown
## <一句话标题>
- 规则 / 事实：能直接照做的一句话
- 怎么确认的：实测命令和结果、对照实验、用户验收；没确认就写「未核」
- 陷阱 / 已排除的说法：（可选）
- 纠正：要改 wiki 哪一页哪一条（可选）
- 出处：会话 ID 或提交号，如 `claude:<会话ID>`、`git:1a2b3c4`
```
